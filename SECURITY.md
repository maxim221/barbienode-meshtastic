# Security

Система рассчитана на доверенную локальную сеть. Встроенный HTTP-сервер не
реализует аутентификацию и не должен публиковаться напрямую в Интернет.

- Ограничьте порты `8081` и `8082` домашней LAN или VPN правилами firewall.
- Не коммитьте экспорт Meshtastic: он может содержать Wi-Fi и channel PSK.
- Не публикуйте `node-location.json` с координатами домашнего узла.
- Задайте уникальный пароль портативной точки (8–63 печатных ASCII-символа).
- Храните SQLite-архив как личные данные: он содержит тексты и идентификаторы.
- Проверяйте SHA-256 и источник образа до прошивки.

Об уязвимости, способной затронуть других пользователей, сообщайте владельцу
репозитория через GitHub Security Advisories, а не публичный issue.
