Что означают RSSI и SNR?

RSSI — мощность принятого сигнала. Чем значение ближе к нулю, тем сигнал сильнее: −70 dBm сильнее −110 dBm.

SNR — отношение сигнала к шуму. Чем выше, тем чище приём. LoRa умеет принимать и при отрицательном SNR; например −5 dB лучше −13 dB.

Что работает без интернета?

Эта страница, журнал и обмен с платой работают внутри вашей Wi‑Fi сети. Сами сообщения уходят и приходят по LoRa. Интернет нужен только для внешних карт.

Как редактировать

Изменяйте только значения справа от двоеточия. Имена полей и $typeName менять нельзя. Числа перечислений задаются их числовыми значениями. Байтовые поля сохраняются как {"$bytes":"base64…"}, а 64‑битные числа — как {"$bigint":"…"}.

Режим устройства

Доступны Meshtastic через домашний Wi‑Fi, портативный Meshtastic AP для прямого подключения телефона и RNode для Reticulum. Одновременно работает только один режим.

Проверяю раздел RNode…

Портативная точка работает по адресу 192.168.4.1 и не изменяет сохранённые параметры домашней сети. После перехода в RNode плата подключится к домашнему Wi‑Fi; при неудаче за 90 секунд она автоматически вернётся в Meshtastic. Аварийный возврат из RNode — удерживать BOOT при включении.

Обновление RNode по Wi‑Fi

Выберите application image RNode для BarbieNode. Он записывается только в неактивный раздел app1; Meshtastic останется рабочим при ошибке или обрыве.

Браузер и плата независимо проверяют SHA‑256 и внутреннюю метку RNode dual‑boot. Загрузка не переключает режим автоматически.
