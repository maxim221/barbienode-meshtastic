Как правильно наводить направленную антенну
  1. Не отключая питание, убедитесь, что подходящая антенна и фидер уже надёжно подключены. Не переставляйте антенный разъём на работающей плате.
  2. Выберите ноду из списка прямого приёма ниже. Для расчётного азимута у нашей и целевой ноды должны быть известны координаты.
  3. Совместите верх телефона с направлением антенны и включите компас. Если компас недоступен, задайте фактический азимут ползунком.
  4. Для сравнения направлений поверните антенну и задайте её фактический азимут компасом или ручным ползунком. Новые прямые пакеты автоматически попадут в соответствующий сектор.
  5. Для точной доводки поворачивайте антенну небольшими шагами по 5–10° и следите за быстрым индикатором. Экран сам пакеты не запрашивает.
  6. Сравнивайте RSSI и SNR нескольких пакетов: RSSI ближе к 0 сильнее, SNR выше — чище. После грубого поиска нажмите «Сбросить лучший сигнал» и уточните максимум.

Отражения от зданий могут дать более сильное направление, чем расчётный азимут. Фиксируйте антенну по устойчивому максимуму нескольких прямых пакетов, а не по одному всплеску.

Что работает без интернета?

Эта страница, журнал и обмен с платой работают внутри вашей Wi‑Fi сети. Сами сообщения уходят и приходят по LoRa. Интернет нужен только для внешних карт.

Краткая инструкция и значения параметров

Как создать приватный канал

  1. Выберите свободный слот и нажмите «Добавить канал».
  2. Задайте короткое имя и нажмите «Новый ключ 256 бит».
  3. Нажмите «Копировать новый ключ» и безопасно передайте имя и ключ только участникам канала. После сохранения ключ снова будет скрыт.
  4. Оставьте MQTT uplink/downlink выключенными, если интернет‑шлюз не нужен, затем нажмите «Сохранить».
  5. На остальных нодах добавьте вторичный канал с тем же именем и точным Base64‑ключом. Один и тот же номер слота не обязателен.

Что означают поля

Слот 0–7
Локальное место канала в устройстве. Все слоты используют общий LoRa‑профиль и одну частоту.
Основной
Определяет радиопрофиль устройства. Редактор не позволяет удалить его.
Вторичный
Дополнительный поток сообщений со своим именем и ключом, но на той же частоте.
Имя
До 11 байт UTF‑8. Имя не является паролем и не открывает канал без PSK.
Ключ PSK
Секрет в Base64: 1, 16 или 32 байта. Для нового приватного канала рекомендуется случайный ключ 32 байта. Пустое поле сохраняет текущий ключ.
Точность позиции
0 — не публиковать позицию в этот канал; 32 — точные координаты; 19 — примерно 50 м; чем меньше число, тем грубее область.
Приглушить
Оставляет канал настроенным, но скрывает его обычные уведомления на клиенте.
AEAD
Аутентифицированное шифрование. Включайте только если все участники используют совместимую прошивку.
MQTT uplink
Разрешает отправку сообщений этого канала в MQTT, если общий модуль MQTT будет включён.
MQTT downlink
Разрешает перенос сообщений из MQTT в LoRa. Может расходовать эфир; без необходимости не включайте.
Отключить канал
Освобождает вторичный слот на этой ноде. У других участников канал не удаляется.

Перед каждым сохранением или отключением интерфейс автоматически скачивает резервную копию с секретами. Храните её локально и не публикуйте.

Как редактировать

Изменяйте только значения справа от двоеточия. Имена полей и $typeName менять нельзя. Числа перечислений задаются их числовыми значениями. Байтовые поля сохраняются как {"$bytes":"base64…"}, а 64‑битные числа — как {"$bigint":"…"}.

Режим устройства

Доступны Meshtastic через домашний Wi‑Fi, портативный Meshtastic AP для прямого подключения телефона и RNode для Reticulum. Одновременно работает только один режим.

Проверяю раздел RNode…

Портативная точка работает по адресу 192.168.4.1 и не изменяет сохранённые параметры домашней сети. После перехода в RNode плата подключится к домашнему Wi‑Fi; при неудаче за 90 секунд она автоматически вернётся в Meshtastic. Аварийный возврат из RNode — удерживать BOOT при включении.

Обновление RNode по Wi‑Fi

Выберите application image RNode для BarbieNode. Он записывается только в неактивный раздел app1; Meshtastic останется рабочим при ошибке или обрыве.

Браузер и плата независимо проверяют SHA‑256 и внутреннюю метку RNode dual‑boot. Загрузка не переключает режим автоматически.
