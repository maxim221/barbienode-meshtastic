# Firmware overlay

Target для ESP32-S3 N16R8 + E22-900M22S и изменения Meshtastic firmware:

- безопасное переключение Meshtastic `app0`, RNode `app1` и MeshCore `app2`;
- проверяемое обновление соседнего application slot;
- защищённая переносная Wi-Fi AP и автоматический fallback через 60 секунд;
- локальный кольцевой JSONL-архив;
- отдельный локальный архив принятых и отправленных сообщений с атомарной
  нормализацией временных меток после синхронизации часов;
- локальные API `/clock/status` и `/clock/sync` для работы архива без
  постоянного доступа к Интернету;
- локальный API `/radio/tx-power` с пределом 2–22 dBm только для этой
  авторизованной RU-установки и установленного E22-900M22S;
- локальный API `/radio/lbt` для постоянного переключателя проверки занятости
  канала CAD перед передачей; безопасное состояние по умолчанию — LBT включён;
- строгий rate-limited ответ на `Ping`;
- RGB-индикатор непрочитанного с прежним heartbeat без индикации передач;
- радуга без подключённых клиентов в переносном AP;
- счётчики принятых и отправленных LoRa-пакетов с момента запуска в локальном
  `/notifications/status` (в отправленные входят ретранслированные пакеты);
- локальный переключатель Ping-бота через `/pingbot/status` и
  `/pingbot/toggle`; выбранное состояние атомарно сохраняется в LittleFS,
  дублируется в NVS и переживает перезагрузку.

Периодический публичный маяк в исходниках явно отключён. Его нельзя включать
без отдельного согласования: для проверки связи используется канал `Ping`, а
автоматический ответ ограничен точным триггером и лимитами частоты.

Таблица `tripleboot_16MB.csv` сохраняет прежние физические адреса Meshtastic,
RNode, NVS и LittleFS. MeshCore занимает свободную область с `0x350000` и
собирается отдельно из `meshcore/` как Companion BLE, не как repeater. Его
независимая настройка мощности доступна в MeshCore Companion в диапазоне
`-9..22 dBm`; предел `22 dBm` относится только к этой авторизованной плате,
E22 и установленной антенне.

Собранные образы не публикуются: их следует получать из проверенного upstream
commit по инструкции в `docs/firmware.md`.
